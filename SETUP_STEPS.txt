LIBRARY MANAGEMENT SYSTEM - SETUP GUIDE
=======================================

You only need Python installed. Everything else is set up automatically.

STEP 1: Extract the zip file
  - Right-click library-app.zip -> "Extract All..." -> Extract.
  - Do not run the project from inside the zip. Extract it first.

STEP 2: Check that Python is installed (first time only)
  - Press the Start button, type "cmd" and press Enter.
  - Type:  python --version   and press Enter.
  - If a version appears (for example Python 3.12.x), you are ready.
  - If you get an error, install Python from python.org/downloads.
    During installation, tick "Add python.exe to PATH" (very important).

STEP 3: Run the project
  - Open the extracted folder and DOUBLE-CLICK "run.bat".
  - A black window opens and installs Flask (1-2 minutes the first time).
  - Your browser then opens the project automatically.
  - If it does not open, go to:  http://127.0.0.1:5000

STEP 4: Stop the project
  - Press Ctrl + C in the black window, or simply close it.

RUNNING FROM VS CODE (if run.bat does not work)
  1. Open VS Code -> File -> Open Folder -> choose the extracted library-app folder.
  2. Open Terminal -> New Terminal.
  3. Run these two commands one by one:
        pip install flask
        python app.py
  4. Open http://127.0.0.1:5000 in your browser.

COMMON PROBLEMS
  - "python is not recognized": Python is not on PATH. Reinstall Python, tick
    "Add python.exe to PATH", then close and reopen the command window.
  - "pip is not recognized": run  python -m pip install flask
  - Port already in use: close the earlier black window and run again.
  - To reset all data: delete the file library.db. A fresh one is created on the next run.

WHAT EACH FILE DOES
  app.py         - the whole backend (database and the logic of every page)
  templates/     - HTML pages (dashboard, books, members, issue / return)
  static/        - CSS (design)
  library.db     - the database (created automatically on the first run)
  run.bat        - double-click to start the project on Windows
